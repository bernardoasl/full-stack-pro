# FullStack Pro 🚀

Este repositório foi criado para armazenar meus exercícios, desafios e projetos desenvolvidos durante o curso **FullStack Pro**.

O objetivo é acompanhar minha evolução no desenvolvimento Full Stack, aplicando na prática os conceitos aprendidos ao longo do curso.

## 📚 Tecnologias estudadas

Durante o curso, serão abordadas tecnologias como:

- HTML5
- CSS3
- JavaScript
- React
- TypeScript
- Next.js
- Node.js
- Nest.js

## 📂 Organização do repositório

Cada pasta representa um módulo, aula ou projeto desenvolvido durante o aprendizado.

Exemplo:


📦 fullstack-pro <br/>
┣ 📂 HTML-CSS <br/>
┣ 📂 JavaScript <br/>
┣ 📂 React <br/>
┣ 📂 TypeScript <br/>
┣ 📂 Projetos <br/>
┗ 📜 README.md


## 🎯 Objetivo

Meu objetivo com este repositório é:

- Praticar desenvolvimento web;
- Criar uma base sólida em programação;
- Registrar minha evolução como desenvolvedor;
- Desenvolver projetos aplicando boas práticas.

## 🚀 Evolução

Este repositório será atualizado conforme avanço no curso e novos projetos forem desenvolvidos.
